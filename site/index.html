How a project gets shaped

From rough block to finished piece

Every project moves through the same four cuts, in order — each one removing a specific kind of uncertainty before the next begins.

Roughing

Discover

We block out the shape of the problem — who the site is for, what it has to do, and what "done" actually looks like.

Shaping

Structure

Information architecture, data models, and admin flows get laid down before a single pixel is styled.

Refining

Build

Front end and back end come together. Catalogues, directories, forms — built to hold real content, not placeholders.

Finishing

Polish

Edge cases, performance, accessibility, and a final pass to sand down anything rough before it ships.
